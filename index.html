01

Locust Infestation Prediction System

Python, Flask, Google Earth Engine, scikit-learn

Acquired and processed satellite and weather data from Google Earth Engine and NASA sources to create features for predicting locust infestation risk. Trained and evaluated KNN and Random Forest classifiers on 50,000 satellite and weather observations using confusion matrices, precision, recall, and F1-score; Random Forest achieved 91% accuracy compared with 74% for KNN. Built a Flask backend that processed user input and served model predictions through a web interface.
